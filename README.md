# دَرْس — تطبيق الدراسة

تطبيق موبايل عربي (RTL) يساعد طالب المدرسة على تنظيم مذاكرته: اختيار الصف الدراسي (١٢ صفاً: ابتدائي وإعدادي وثانوي)، إدارة المواد والمهام، جلسات مذاكرة بمؤقّت وهدف زمني، دروس فيديو من يوتيوب للمنهج المصري متاحة دائماً داخل التطبيق، ومراجعة لاختبارات الشهر — كل ذلك محلياً على الجهاز، دون حساب أو تسجيل دخول. ويعرض الملخص إحصائيات تحفيزية (سلسلة أيام المذاكرة ووقت الأسبوع ونسبة إنجاز المهام)، ويدعم النسخ الاحتياطي الكامل تصديراً واستيراداً.

## التشغيل

```bash
pnpm install
pnpm start        # Expo dev server
pnpm android      # التشغيل على Android
pnpm ios          # التشغيل على iOS
pnpm web          # التشغيل على الويب
```

## الفحوصات

```bash
pnpm check   # فحص الأنواع (TypeScript)
pnpm lint    # ESLint
pnpm test    # Vitest
```

## البنية

- `app/(tabs)/` — الشاشات الست: الملخص، الدروس، المهام، جلسة مذاكرة، اختبارات الشهر، المواد.
- `components/` — عناصر الواجهة والنماذج العربية.
- `hooks/use-study-store.tsx` — مخزن الحالة المحلية وأوامر تغييرها.
- `lib/study-types.ts` — أنواع البيانات ومخططها.
- `lib/study-schema.ts` — التحقق النقي من بنية البيانات (مخطط v1) وتحليل الحفظ، بلا اعتماد على React Native.
- `lib/study-storage.ts` — القراءة والكتابة في AsyncStorage، مع نسخة أمان تلقائية تُسترجع عند تلف النسخة الأساسية.
- `lib/study-backup.ts` — تصدير/استيراد النسخة الاحتياطية (JSON) مع التحقق الكامل قبل أي استيراد.
- `lib/study-utils.ts` — الفرز والتنسيق والحسابات.
- `lib/study-stats.ts` — الإحصائيات التحفيزية: سلسلة الأيام، وقت اليوم/الأسبوع، نسبة إنجاز المهام، وتصنيف مهام اليوم والأسبوع.
- `lib/lessons.ts` — كتالوج دروس يوتيوب الموثقة حسب الصف والمادة، ومواد المنهج المصري لكل صف.
- `components/backup-panel.tsx` — لوحة النسخ الاحتياطي في الشاشة الرئيسية (تصدير بالمشاركة واستيراد بلصق النص).

## الدروس واختبارات الشهر

- تبويب «الدروس» يعرض فيديوهات وقوائم تشغيل يوتيوب موثقة لصف الطالب ومواده، بمشغّل مدمج داخل التطبيق وتتبّع للمشاهدة. قائمة الدروس محفوظة داخل التطبيق دائماً؛ التشغيل نفسه يتم عبر يوتيوب ويحتاج إنترنت.
- تبويب «اختبارات الشهر» يتيح تسجيل نتيجة كل اختبار شهري مع ملاحظات مراجعة للأخطاء، وملخص شهري بمتوسط النتائج وأفضلها.

## البيانات والخصوصية

- كل بيانات الطالب (الصف، المواد، المهام، الجلسات، اختبارات الشهر، الدروس المشاهَدة) تُحفظ على جهازه فقط في AsyncStorage.
- لا يوجد خادم، ولا حسابات، ولا تُرسل أي بيانات إلى أي جهة.
- لحماية البيانات: تُحفظ نسخة أمان تلقائية من الحفظ السابق تُسترجع إذا تلفت النسخة الأساسية، ويمكن من الشاشة الرئيسية تصدير نسخة احتياطية كاملة (JSON) عبر نظام المشاركة واستيرادها لاحقاً بلصق نصها — والاستيراد يتحقق من البنية كاملة قبل استبدال أي بيانات. حذف التطبيق أو مسح بياناته يمحو النسختين معاً، لذا يُنصح بالاحتفاظ بنسخة مصدّرة خارج الجهاز.

## بناء Android

يُبنى ملف Android من مسار البناء الرسمي للمشروع بعد اجتياز `pnpm check` و`pnpm test` وبناء حزمة JavaScript بنجاح (`npx expo export --platform android`). لا يُعلن أي إصدار جاهزاً قبل وجود ملف فعلي قابل للتثبيت ونتيجة بناء ناجحة.
