# دَرْس — تطبيق الدراسة

تطبيق موبايل عربي (RTL) يساعد طالب المدرسة على تنظيم مذاكرته: اختيار الصف الدراسي (١٢ صفاً: ابتدائي وإعدادي وثانوي)، إدارة المواد والمهام، جلسات مذاكرة بمؤقّت وهدف زمني، دروس فيديو من يوتيوب للمنهج المصري متاحة دائماً داخل التطبيق، ومراجعة لاختبارات الشهر — كل ذلك محلياً على الجهاز، دون حساب أو تسجيل دخول.

## التشغيل

```bash
pnpm install
pnpm start        # Expo dev server
pnpm android      # التشغيل على Android
pnpm ios          # التشغيل على iOS
pnpm web          # التشغيل على الويب
```

## الفحوصات

```bash
pnpm check   # فحص الأنواع (TypeScript)
pnpm lint    # ESLint
pnpm test    # Vitest
```

## البنية

- `app/(tabs)/` — الشاشات الست: الملخص، الدروس، المهام، جلسة مذاكرة، اختبارات الشهر، المواد.
- `components/` — عناصر الواجهة والنماذج العربية.
- `hooks/use-study-store.tsx` — مخزن الحالة المحلية وأوامر تغييرها.
- `lib/study-types.ts` — أنواع البيانات ومخططها.
- `lib/study-storage.ts` — القراءة والكتابة في AsyncStorage مع التحقق من بنية البيانات (مخطط مُصدّر v1).
- `lib/study-utils.ts` — الفرز والتنسيق والحسابات.
- `lib/lessons.ts` — كتالوج دروس يوتيوب الموثقة حسب الصف والمادة، ومواد المنهج المصري لكل صف.

## الدروس واختبارات الشهر

- تبويب «الدروس» يعرض فيديوهات وقوائم تشغيل يوتيوب موثقة لصف الطالب ومواده، بمشغّل مدمج داخل التطبيق وتتبّع للمشاهدة. قائمة الدروس محفوظة داخل التطبيق دائماً؛ التشغيل نفسه يتم عبر يوتيوب ويحتاج إنترنت.
- تبويب «اختبارات الشهر» يتيح تسجيل نتيجة كل اختبار شهري مع ملاحظات مراجعة للأخطاء، وملخص شهري بمتوسط النتائج وأفضلها.

## البيانات والخصوصية

- كل بيانات الطالب (الصف، المواد، المهام، الجلسات، اختبارات الشهر، الدروس المشاهَدة) تُحفظ على جهازه فقط في AsyncStorage.
- لا يوجد خادم، ولا حسابات، ولا تُرسل أي بيانات إلى أي جهة.
- حذف التطبيق أو مسح بياناته يمحو هذه البيانات نهائياً — النسخ الاحتياطي والتصدير/الاستيراد على خارطة الطريق (المرحلة 1 من خطة التحسين).

## بناء Android

يُبنى ملف Android من مسار البناء الرسمي للمشروع بعد اجتياز `pnpm check` و`pnpm test` وبناء حزمة JavaScript بنجاح (`npx expo export --platform android`). لا يُعلن أي إصدار جاهزاً قبل وجود ملف فعلي قابل للتثبيت ونتيجة بناء ناجحة.
