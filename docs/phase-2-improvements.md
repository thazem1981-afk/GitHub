# سجل تنفيذ المرحلة ٢ — تحسينات خطة v2 (2026-11-03)

نُفّذت المراحل ٢-أ إلى ٢-د من `docs/improvement-plan-v2.md` واحدة تلو الأخرى:

## ٢-أ حماية البيانات
- `lib/study-schema.ts` (جديد): نقل التحقق من بنية بيانات v1 إلى وحدة نقية بلا أي اعتماد على React Native، مع `parseStoredState` و`normalizeStudyState` — نفس القواعد السابقة حرفياً، قابلة الآن للاختبار وإعادة الاستخدام.
- `lib/study-storage.ts` (أعيدت كتابته حول الوحدة الجديدة): قبل كل حفظ تُحفظ النسخة السابقة في مفتاح أمان `dars.study.state.v1.backup`، وعند الإقلاع إذا تلفت النسخة الأساسية تُسترجع نسخة الأمان بدل فقدان البيانات.
- `lib/study-backup.ts` (جديد): تصدير/استيراد نسخة احتياطية JSON بمغلّف `{app, kind, version, exportedAt, state}`؛ الاستيراد يتحقق من البنية كاملة قبل قبول أي استبدال، ويقبل أيضاً نص الحفظ الخام.
- `components/backup-panel.tsx` (جديد) في الشاشة الرئيسية: تصدير عبر نظام المشاركة، واستيراد بلصق النص مع تأكيد صريح قبل الاستبدال ورسائل نجاح/فشل واضحة.
- المخزن (`hooks/use-study-store.tsx`): أُضيف `exportBackup` و`importBackup` (الاستيراد يمر عبر نفس طابور الحفظ، فتُحفظ نسخة أمان من البيانات الحالية تلقائياً قبل الاستبدال).

## ٢-ب إحصائيات تحفيزية
- `lib/study-stats.ts` (جديد): سلسلة أيام المذاكرة (لا تنكسر صباحاً قبل أول جلسة)، وقت اليوم وآخر ٧ أيام، نسبة إنجاز المهام، تقدّم الجلسة نحو هدفها، ومهام اليوم/الأسبوع. وقت الجلسة يُنسب ليوم انتهائها (أو إنشائها إن كانت مفتوحة).
- الشاشة الرئيسية: بطاقة «أسبوعك» — السلسلة، وقت الأسبوع، شريط تقدّم المهام، وشارة حمراء بعدد المهام المتأخرة عند وجودها.

## ٢-ج إنتاجية المهام
